# JDI GOLD Website

This repository contains the static JDI GOLD homepage.

## Publish with GitHub Pages

1. Upload the contents of this folder to the `main` branch of a GitHub repository.
2. Open the repository's **Settings > Pages**.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.
4. Open the **Actions** tab and wait for the deployment workflow to complete.

The published address will use this format:

`https://YOUR_GITHUB_USERNAME.github.io/YOUR_REPOSITORY_NAME/`
